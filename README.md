## 🚀 Projects

### 📈 Data Science & Analysis

**[The Economic Aftershocks — Earthquake Impact on National Recovery](https://github.com/betlm/DSA210_project)**
&nbsp;`DSA 210 · Introduction to Data Science · Sabancı University`

Merged three heterogeneous datasets (EM-DAT, World Bank API, USGS) covering 959 earthquake events across 110 countries. Applied non-parametric hypothesis testing (Spearman, Kruskal-Wallis, Mann-Whitney U) and built Random Forest & Logistic Regression classifiers for economic recovery prediction — achieving a **20.8 pp F1-score improvement** over baseline.
